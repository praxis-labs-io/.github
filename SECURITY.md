# Security

Report anything with a security angle privately first. Do not open a public
issue for a vulnerability.

## Reporting

Use GitHub's private vulnerability reporting: on the repository's **Security**
tab, choose **Report a vulnerability**. It opens a private thread visible only
to the maintainers.

Include what you would put in any bug report: the version, your OS, and the
steps. If you have a proof of concept, attach it.

You will get a first reply within a week. If you do not, open a public issue
saying only that you are waiting on a security report, with no details in it.

## Scope

The current release, and `main`. Older versions get a fix by way of the next
release rather than a backport.
